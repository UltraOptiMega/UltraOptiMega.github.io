This repository is a static documentation site built with MkDocs and the Material theme. It contains only two files: `mkdocs.yml` (site configuration) and `docs/index.md` (the default landing page). There is no application code, no source files, and no logging framework or logging infrastructure present. The project is purely a documentation generator configuration with no runtime behavior that would require logging.
