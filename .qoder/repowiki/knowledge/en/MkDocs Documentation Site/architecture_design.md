Single-page MkDocs project rooted at the repository root. `mkdocs.yml` declares the Material theme (with indigo palette, dark/light mode toggle, instant navigation, search, and code copy features) and enables Markdown extensions (`pymdownx.highlight`, `superfences`, `tabbed`, `admonition`, `details`, `attr_list`, `md_in_html`). The `docs/` directory holds the site content; currently only `index.md` serves as the homepage. There are no nested sub-pages or additional assets — the site is intentionally minimal.
